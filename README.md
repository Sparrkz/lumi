# Lumi

Lumi is a calm, adaptive learning product concept designed around helping people understand where they are, what they need next, and how to keep building confidence over time.

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Included

- Landing page for the Lumi product story
- Onboarding flow prototype
- Warm, accessible visual system shaped by the product design brief
