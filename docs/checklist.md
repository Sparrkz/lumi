# The one thing I would NOT do

Don't tell an AI coding tool:

> "Build me Lumi, an adaptive learning platform."

That's how you end up with a beautiful dashboard and a fundamentally shallow product.

Instead, we should **design Lumi's brain before its body.**

The most important intellectual work is:

```text
                    Lumi
                     │
             ┌───────┴───────┐
             │               │
          HUMAN           KNOWLEDGE
             │               │
       Learning DNA      Knowledge Graph
             │               │
             └───────┬───────┘
                     │
              ADAPTIVE ENGINE
                     │
        ┌────────────┼────────────┐
        │            │            │
     WHAT?        HOW?          WHEN?
```
