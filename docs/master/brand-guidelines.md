# 01. Brand Foundation

## 1.1 What is Lumi?

Lumi is a universal adaptive learning environment designed to help people learn, develop skills, solve problems, explore ideas, and grow throughout life.

Lumi is not limited to:

* schools
* classrooms
* exams
* academic subjects
* children
* professional training

Lumi exists wherever a person wants to understand something, become capable of something, or explore something new.

---

# 02. The Brand Idea

Lumi is built around one fundamental belief:

> **People do not all learn the same way, at the same pace, or for the same reasons.**

Therefore, learning technology should adapt to the person—not force the person to adapt to the technology.

Lumi's adaptive system is designed to respond to behavior and learning evidence rather than diagnose or label the learner. 

---

# 03. Brand Promise

> **Lumi meets you where you are and helps you move forward.**

This is the central promise behind the entire brand.

Lumi should never communicate:

> "You are behind."

It should communicate:

> **"Here's where you are. Here's what could help next."**

---

# 04. Brand Vision

> **A world where everyone has a place to learn, grow, and become capable of more.**

---

# 05. Brand Mission

> **To create an adaptive learning environment that understands each person's journey and helps them develop meaningful capabilities throughout life.**

---

# 06. Brand Philosophy

Lumi is built on six principles.

### 01 — The learner comes first

The lesson is not the center.

The learner is.

The existing adaptive architecture explicitly moves from a lesson-centered model toward a learner-centered loop involving the knowledge graph, adaptive engine, recommendation system, learning experience, assessment, and continual updating. 

---

### 02 — Growth over judgment

Lumi should help people understand what they can do next.

It should not make them feel measured, ranked, or inadequate.

---

### 03 — Adaptation over standardization

Lumi should adjust:

* pacing
* complexity
* guidance
* information density
* lesson structure
* review
* challenge

based on evidence.

The existing adaptive specification specifically defines adaptive pacing, complexity, guidance, layout density, and challenge state. 

---

### 04 — Accessibility is belonging

Accessibility is not an add-on.

A person should not need to identify themselves as "different" before Lumi becomes usable for them.

---

### 05 — CLumiosity is learning

Not every interaction needs to become a course.

Sometimes someone simply wants to ask:

> "Why does this happen?"

Lumi should make that cLumiosity valuable.

---

### 06 — Intelligence should feel calm

Lumi is intelligent without being intimidating.

The previous design direction specifically established:

> **High-tech but calm.**

and rejected neon/cyberpunk aesthetics in favor of readable typography, intelligent whitespace, subtle depth, and restrained visual effects. 

---

# 07. Brand Personality

Lumi is:

### CLumious

Lumi encourages exploration.

### Intelligent

Lumi understands context and recognizes patterns.

### Calm

Lumi does not overwhelm the learner.

### Encouraging

Lumi welcomes different people and different ways of learning.

### Humble

Lumi changes when the learner's needs change.

# 38. Typography Rules

Never use typography purely for decoration.

Every level should establish information hierarchy.

Body text should remain comfortable for long reading.

The previous system specified approximately 15px body text with a 1.65 line height, which is a useful baseline for Lumi's readability-first approach.

Every meaningful sound must have a visual alternative.

Users should be able to disable nonessential sound.

---

# 96. Character Motion

The owl should have restrained expressions:

* cLumious
* thinking
* encouraging
* celebrating
* resting
* observing

Avoid exaggerated cartoon behavior as the default.

# 97. Character MatLumity

The same character can become visually more restrained as the learner's interface matLumity increases.

The underlying character identity remains consistent.

# 98. Lumi Visual Hierarchy

The hierarchy should generally be:


```text
Technology without coldness.

Personality without childishness.
Simplicity without emptiness.
Depth without complexity.
```

# 102. Brand Checklist

Before approving any Lumi asset, ask:

### Identity

* Does it feel unmistakably Lumi?

### Warmth

* Does it feel human?

### Intelligence

* Does it feel capable?

### Calmness

* Is there unnecessary visual noise?

### Inclusivity

* Does it welcome different people?

### Age

* Would it work for different generations?

### Accessibility

* Can the message survive without color or motion?

### Adaptability

* Can the experience change without breaking the identity?

### Timelessness

* Will this still look good several years from now?

# 103. Lumi Brand Do / Don't

| Do                           | Don't                     |
| ---------------------------- | ------------------------- |
| Use warmth                   | Make everything orange    |
| Use intelligent whitespace   | Fill every space          |
| Use character contextually   | Put the owl everywhere    |
| Use subtle motion            | Animate everything        |
| Show growth                  | Obsess over scores        |
| Explain adaptation           | Expose technical states   |
| Support different users      | Label users               |
| Use sophisticated typography | Use childish type         |
| Use real-world imagery       | Use generic stock imagery |
| Make AI calm                 | Make AI flashy            |
| Use meaningful color         | Rainbow-code everything   |
| Encourage cLumiosity          | Force a course            |
